Overview

This project contains an Excel VBA automation solution developed to organize and standardize spare parts data for shipyard vessels. The macro automates repetitive formatting, data-cleaning, and categorization tasks that were previously performed manually.

The objective was to improve data quality, reduce manual effort, and create a consistent structure for spare parts records used in vessel maintenance and operational processes.

Key Features
Automated spare parts data organization
Standardized data formatting and structure
Removal of duplicate and unnecessary records
Improved consistency across datasets
Faster preparation of spare parts inventories and reports
Reduced manual processing time and human error
Business Impact

The automation significantly reduced the time required to prepare and organize spare parts datasets, allowing users to focus on analysis and operational activities rather than manual spreadsheet work.

Benefits achieved:

Faster processing of large spare parts inventories
Improved data accuracy and consistency
Reduced repetitive manual workload
Enhanced operational efficiency
